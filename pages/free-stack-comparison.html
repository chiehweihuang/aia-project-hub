FREE-STACK ANALYSIS

免費自組方案完整比較

十套「完全免費（無授權費）」的 WordPress 外掛大軍加免費 SaaS 組合，能不能兜出跟 netiCRM 一樣的功能？逐套列出涵蓋範圍、硬限制與所需人工，並把人工以業界行情換算成現金。這是「網站平台兩路線評估」裡路線 B「免費大軍」這條路的成本底細。

00 / CONCLUSION

一句話結論

一句話

「完全免費（無授權費）」的方案兜得出來，但沒有一個是「免費方案」。每一塊都要人工建置加每月維護。把人工以業界行情入帳，一個能用的完整站第一年人工約數十萬元，而 netiCRM 第一年約 NT$12,960（人工近零）。量級差距明確（自組遠高於 netiCRM），但確切倍數依維護複雜度與時薪職類而定，不宜釘死單一數字。

差額全部是人力，不是軟體。唯一能讓自組划算的條件，是有人願意免費、或以遠低於市場價做這些建置與每月維護的工。

「免費」指的是沒有軟體授權或訂閱費。金流交易手續費照樣有（netiCRM 也一樣），抵稅收據一律手動。下面三節依序回答：台灣金流為什麼讓多數免費方案在台灣等於沒有金流、十套組合各自缺什麼、以及把人工攤開後實際要多少錢。

01 / PAYMENT

台灣金流現況：為什麼多數免費方案在台灣沒有金流

不是費率問題，是台灣根本開不了戶、不能做境內收款。三大國際金流對台灣 ADALS 售票都不能當收款後端：

三大國際金流為什麼不能當台灣 ADALS 售票後端（2026-06 查證）
服務 能當台灣售票後端 根本原因
PayPal 不可用，只能收海外 官方寫明「僅支援傳送跨國付款至台灣境外註冊的 PayPal 帳戶」，台灣付款人付不了台灣收款人。費率 4.40% 加固定費。只能當海外與會者的輔助通道。
Stripe 不可用，開不了戶 開戶國家清單沒有台灣，台灣法人只能用到測試模式，不能開正式收款。要繞外國法人或代收商，收款主體就不是 AIA。
Square 不可用，台灣沒服務 只在美、加、英、澳、日、愛爾蘭、法、西營運，台灣不在清單，根本註冊不了。

真正能用的是台灣本地金流，但只有藍新是零固定費起步，其餘都有年費或設定費：

兩個要點。只有藍新是零固定費起步（其餘都有年費或設定費）；而所有金流都不負責抵稅收據，收據永遠是 NGO 自己的事。這也是為什麼多數只接 Stripe 或 PayPal 的免費外掛，在台灣等於沒有金流，最後都被迫回到「WooCommerce 加藍新或綠界」。

跨五十項的共通鐵律（每一項都中）

  1. 免費的是「授權費」，不是金流費、不是人工。
  2. 多數免費外掛的金流只接 Stripe 或 PayPal，在台灣等於沒有金流，被迫回 WooCommerce 加藍新或綠界。
  3. 抵稅收據沒有任何免費工具自動完成，永遠是 NGO 人工加財政部 Windows 軟體上傳。
  4. 自託管選項（NocoDB / Baserow / n8n）免授權費，但換成要你養伺服器、當兼職 DevOps。

04 / THIRD PATH

第三條路：不一定要在「免費自組」和「netiCRM」之間二選一

破口：這些是純票務、不是 CRM，沒有跨活動聯絡人庫與捐款收據整合；無障礙未公開聲明，數位無障礙協會用未公開合規的平台有形象風險。只在「單次活動、純票務、不需 CRM 或抵稅收據」前提下成立。

B. 自託管開源（把現金換成志工工時）

  • Pretix 自託管：是少數有外部 WCAG 2.1/2.2 AA 無障礙審計依據的開源票務平台（僅前台、後台未審計），對數位無障礙協會的形象一致性有價值；但無台灣本地金流現成外掛，需自寫綠界/藍新外掛。來源
  • 自架 netiCRM（NETivism 的 CiviCRM 台灣 fork，AGPL）：零授權費且原生支援台灣金流（藍新、綠界、LINE Pay、TapPay），但需 Drupal 與 LAMP 維運能力、官方無自架支援文件，實務上要長期技術人力。來源
  • 免費台灣金流關鍵元件 RY Tools for WooCommerce：免費、整合綠界與藍新、2026 仍活躍維護，是自架 WordPress 接台灣金流最成熟的免費路徑；綠界海外信用卡須為特約賣家才可在後台開啟。來源

這條路同樣把成本從「現金」換成「志工工時」，所以回到下一節的高風險依賴：要有長期技術志工才成立。

05 / VERDICT

結論與判斷

免費軟體不等於免費方案。自組 WordPress 在台灣划算的唯一條件，是有人願意免費、或以遠低於市場價（等於 netiCRM 年費除以年工時，約 NT$36/hr，低到不現實）做建置與每月維護。

判斷依據

若有長期免費志工工程師，自組才有意義（省的是現金，花的是那位志工的時間）。但這個前提是高風險依賴：志工留任率偏低、技術志工常見「建置完成即離開」，人一走，金流、對帳、外掛更新、無障礙維護就斷（經 codex 雙模型查核確認）。

沒有，以業界行情，自組第一年人力成本就遠超 netiCRM 數年的費用，且無障礙、對帳、合規、key-person 風險全要自己扛。

所以給理事會的問題不是「能不能免費兜出來」（能），是「誰要長期免費維護這個多系統拼裝站，而且人走了誰接」。

06 / METHOD

方法與限制

  • 金流可用性（Stripe 與 Square 無台灣、PayPal 只跨境）為 2026-06 查證，屬會變動項，簽約前再確認。
