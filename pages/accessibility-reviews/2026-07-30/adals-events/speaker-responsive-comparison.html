活動頁講者與票券響應式調整比較

給設計與 WordPress 製作人員的畫面比較與設定依據。本頁只談 ADALS 活動頁的講者卡與票券卡。

先看採用方式

左側是 2026-07-31 正式站原始畫面；右側是在本機瀏覽器暫時加入響應式 CSS 後的結果。這些預覽沒有修改 WordPress、正式站或 staging。

本頁採用 Kadence Blocks 原生的三段 responsive 設定：Mobile 小於 768px、Tablet 768–1024px、Desktop 大於 1024px。講者在 Tablet 使用兩欄，目前三位講者會排成 2+1；票券在 Tablet 使用兩欄、Desktop 使用四欄。沒有另外建立平板專用 Row Layout，也不依賴自訂 CSS breakpoint。

欄數與對齊規則

講者卡

Mobile 一欄，Custom Content Max Width 設為 520px並置中；Tablet 兩欄，最大內容寬度 976px；Desktop 三欄。Mobile Row Layout 左右 padding 保留 24px。Tablet 目前呈現 2+1，增加講者後會依兩欄繼續換行。

票券卡

Mobile 一欄；Tablet 兩欄；Desktop 四欄。Desktop Custom Content Max Width 設為 1648px，欄距與卡片內距各 16px；Tablet 欄距與內距各 24px。票種名稱、價格與報名區在同一列對齊。

文字與顏色

票券的「包含／Includes」目前為 18px 一般字重，灰字對白底約 4.02:1；修改後加深為 #4a5568，約 7.53:1。其餘色彩與整體視覺不變。

票券內容一併修正

中英文小標一致

第二至第四張卡的英文清單前仍顯示中文「包含」，建議與第一張一致改成「Includes:」。

線上票文字一致

「僅提供線上活動 access」建議改成完整中文，例如「僅提供線上活動參與」；「提供3個月」的數字前後空格也與其他卡一致。

報名連結已知待補

目前四個「報名｜Register」沒有連結，所以無法使用 Tab 選取。此項已知，待 Accupass 網址確認後，再改成真正的連結並複查鍵盤操作。

只使用 Kadence Blocks 的設定方式

這一版不使用額外 CSS。所有欄數、最大寬度、間距、內距、等高與內容分組，都由目前頁面已有的 Row Layout、Column／Section、Advanced Heading 與 Advanced Button 完成。

講者 Row Layout

  1. 在清單檢視選取包住三張講者卡的 Row Layout。
  2. Layout 的 responsive 欄數設為：Desktop 3、Tablet 2、Mobile 1。
  3. Custom Content Max Width 設為：Desktop 1200px、Tablet 976px、Mobile 520px。
  4. Column and Row Gutters 設為 24px，並開啟 Inner Column Height 100%（來源：Kadence Row Layout 官方說明）。
  5. Mobile 的 Row Layout 左右 padding 設為 24px；不要設為 0。
  6. 三張文字內容 Section 的左右 padding 設為 24px。

若要讓三張桌面卡的 English bio 與外部連結在同一水平線：在每張文字內容 Section 內，將「姓名與介紹」放進第一個內層 Section，將「English bio 與 LinkedIn」放進第二個內層 Section；父層 Section 的 Direction 設為 Vertical、Justify Content 設為 Space Between、Flex Grow 設為 1。這仍是同一張 Kadence 卡片，只是整理既有內容的內層分組。

未來增加講者時：沿用同一欄數規則即可。四位會排成 Tablet 2+2／Desktop 3+1；五位是 Tablet 2+2+1／Desktop 3+2；六位是 Tablet 2+2+2／Desktop 3+3。新增實際講者卡即可，不先放空白卡片。

票券 Row Layout

  1. 選取包住四張票券的 Row Layout，responsive 欄數設為：Desktop 4、Tablet 2、Mobile 1。
  2. Custom Content Max Width 設為：Desktop 1648px、Tablet 976px；Mobile 維持自動寬度。
  3. Column and Row Gutters 設為：Desktop 16px、Tablet 24px、Mobile 24px。
  4. 四張票券 Column／Section 的左右 padding 設為：Desktop 16px、Tablet 24px、Mobile 24px，並開啟 Inner Column Height 100%（來源：Kadence Row Layout 官方說明）。
  5. 把每張雙語票種名稱放進一個內層 Section；四個名稱區使用相同的 responsive Minimum Height，先以 Desktop 96px、Tablet 88px、Mobile 自動高度測試，使價格起點一致。
  6. 把「票種名稱到英文說明」放進第一個內層 Section，Advanced Button 保留為第二個子項目；父層票券 Section 設為 Vertical、Justify Content 設為 Space Between。按鈕便會貼齊卡片底部。
  7. 「包含／Includes」的 Advanced Heading 文字顏色改為 #4a5568。

相關控制項可對照 Kadence Row Layout 官方說明與 Section Flexbox 官方說明。

Kadence 原生 breakpoint：Mobile 小於 768px、Tablet 768–1024px、Desktop 大於 1024px。Row Layout 的三段設定會讓講者在整個 Tablet 區間維持兩欄，三位講者因此呈現 2+1。

測試方式與原始資料

以 2026-07-31 的 live rendered DOM 為準，逐一量測 320／768／1024／1280／1440／1742／1920px，並另外補測 375／600／767px 的 Mobile 區間。每個主要寬度先截原始畫面，再暫時注入與上述 Kadence block 設定相同的 computed styles、重新量測與截圖。測試用注入只用來預覽尚未儲存的區塊設定，不是交付給 WordPress 的 CSS。
