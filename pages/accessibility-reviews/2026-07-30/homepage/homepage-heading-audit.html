AIA 首頁 Heading 結構檢查與修改對照

日期：2026-07-30
範圍：AIA 首頁 live rendered DOM
目的：逐項說明目前 25 個 heading，以及畫面上應補成 heading 的 3 個卡片名稱，提供可直接在 WordPress／Kadence 執行的修改對照。

先說結論

目前：H1 × 1、H2 × 7、H3 × 3、H4 × 1、H5 × 13，共 25 個 heading；「三大價值」的 3 個卡片名稱只是粗體文字。

建議完成後：H1 × 1、H2 × 7、H3 × 19、H4 × 0、H5 × 0，共 27 個 heading。

  • 「亞太包容創新協會」保留為全頁唯一 H1。
  • 七個主要區段保留 H2。
  • 區段內的圖文卡標題、「三大價值」區段內三張完整卡片的名稱、六筆年份、三張連結卡與四個議題名稱使用 H3。
  • 頁首插圖下方重複出現的「多元共融／以人為本／科技創新」只是摘要標籤，保留一般文字，不加入 heading 清單。
  • Hero 介紹句改為一般段落，不進入 heading 導覽。
  • 修改的是 HTML 語意；原本的字級、顏色、間距與版面可保留。

判斷 Heading 的原則

  • 先看內容角色：這段文字是否命名後面的一組獨立內容？是，才可能使用 heading。
  • 摘要不是章節：只有短標籤或重複提示、後面沒有它所帶領的內容，就保留一般文字。
  • 同層項目用同層級：同一個 H2 區段內並列的卡片、年份或項目使用 H3，不因字比較小而改用 H5。
  • 視覺大小與 HTML 層級分開：先決定 H1、H2、H3 的內容關係，再用 typography 保留原本字級與樣式。
  • 不要只看文字是否重複：相同文字可能在頁首是摘要、在內文是卡片名稱；應依它與後續內容的關係判斷。

為什麼這項修正重要

Heading 是頁面的導覽骨架。只看畫面時，可以利用字體大小、卡片位置和背景判斷內容關係；使用螢幕閱讀器的人則常打開 heading 清單，或按快捷鍵逐個 heading 跳轉。現在的標記會造成三種具體問題：

  • H1 後直接出現 H4，使 Hero 介紹句看起來像位於不存在的 H2、H3 區段之下。
  • 「協會大事記」等 H2 後直接出現 H5，使年份與卡片看起來像深層子章節，而中間三層並不存在。
  • 「三大價值」區段內的「多元共融」「以人為本」「科技創新」各自帶領一張包含圖片與說明文字的完整卡片，卻不在 heading 清單中；使用 heading 導覽會略過這三個內容項目。

文字本身仍可能被逐字讀到，問題不是「完全讀不出來」，而是頁面大綱沒有忠實表達畫面上的區段與父子關係。這會增加定位、略讀和回到特定區段的成本。

判斷原則：只有當一段文字命名後續的一組獨立內容，才使用 heading。頁首的三個短摘要沒有各自帶領內文，因此維持一般文字；「三大價值」區段的三個卡片名稱各自帶領一段完整說明，因此使用 H3。重複出現本身不是增加 heading 的理由。

單純出現 H2 後接 H5，不是每次都能只靠數字直接判定為 WCAG 違規；這一頁需要修正，是因為 heading 標記和畫面已呈現的內容關係明顯不一致。

測試界線：這是根據 rendered HTML 與 accessibility tree 所做的結構檢查，沒有執行 NVDA、JAWS 或 VoiceOver 的完整操作走查。修正後仍需在 staging 以 heading list 複查順序，再完成螢幕閱讀器實機測試。

  • 主要區段使用 H2。

  • Hero 說明是一般段落。
  • 不以 H5／H6 控制小字外觀。

因 7/30 畫面改版而調整

  • 7/3 的英文 H6 視覺標籤已不在目前 heading 清單中。
  • 「關於我們」三句在新版畫面中各自帶領一組圖文內容，因此保留 H3；7/3 畫面把它們當成段落，當時才建議改成 paragraph。
  • 頁首三個價值摘要維持一般文字；只有「三大價值」區段內帶領完整說明的三個卡片名稱使用 H3。

WordPress／Kadence 實作步驟

  1. 進入「頁面 → 全部頁面 → 首頁 → 編輯」。
  2. 打開左上角「清單檢視」，依本文件的逐項對照尋找對應文字。
  3. 選取 Kadence Advanced Heading 時，在右側區塊設定尋找 HTML Tag／Heading Tag，依對照改成 H1、H2 或 H3。
  4. 使用 WordPress 核心 Heading block 時，從區塊工具列更改 heading level。
  5. Hero 介紹句若現有區塊可把 HTML Tag 設為 p，直接改 tag；若只支援 H1–H6，改用 Paragraph／Kadence Advanced Text，再套用原本字級、顏色與間距。
  6. 在「三大價值」區段內，三個卡片名稱若目前與內文放在同一個 Paragraph，分成「H3 名稱」與「一般段落」兩個區塊。不要修改頁首插圖下方的三個短摘要。
  7. 儲存草稿後先預覽，確認 tag 調整後既有視覺樣式維持一致。
