# AIA 首頁無障礙與響應式版面檢查

測試網址：https://aia.tinyoakstudio.com/  
測試日期：2026-07-30

## 結論

首頁與 ADALS 活動頁分開記錄。首頁目前有 6 項上線前應先處理的問題；「關於我們」三組圖文卡確實需要改 CSS。首頁需要先上線，用來展示協會資訊、宣傳活動，並承接購票入口，因此不必等待整套版面調整完成。CSS 先在保留的 staging 驗證，確認沒有斷版後再套到正式站。這次只做 live 網頁的只讀檢查，沒有修改正式網站或 staging。

## P0

1. 補上首頁 `<title>`，例如「亞太包容創新協會｜APAC AIA」。
2. 修正 heading tag：這是整頁的導覽骨架，不是字級或視覺樣式問題。螢幕閱讀器使用者常透過標題清單或逐個標題跳轉；目前 H2 後直接出現 H5、hero 介紹句是 H4，「三大價值」卡片名稱則不是 heading，會使區段關係不清楚或在標題導覽中被略過。全頁應保留一個 H1；主要區段 H2；卡片名稱與年份 H3；hero 標語改一般段落。原有視覺樣式可由 CSS 保持不變，因此建議在上線前完成。
3. 「了解志工機會」目前是 `div/span`，不是連結，Tab 不會停在這裡。目的頁完成後改成真正的 `<a href>`；之前先取消按鈕外觀。
4. 修正「關於我們」響應式 CSS：
   - 320px：內文的左右 margin 與 padding 疊加，實際字欄只剩約 85–105px。
   - 768px：仍維持兩欄，圖片約 351–353px 高，文字卡約 799–957px 高。
   - 900px 以下改單欄；900px 以上讓圖片以 `object-fit:cover` 填滿同列。
5. 桌面導覽的「論壇活動 Event」與「聯繫 Contact」對比為 4.16:1，需調到 4.5:1。
6. 目前可見內容以繁體中文為主，根節點應改為 `zh-TW` 或 `zh-Hant`；完整英文段落另標 `lang="en"`。

這項 CSS 應納入本次上線。若時間允許，先在 staging 完整驗證，再與本次內容一起套到正式站。若為了活動宣傳與購票入口必須先行上線，可先公開內容，但需保留 staging，並將 CSS 驗證與正式站修正列為上線後立即完成的後續工作。
