這頁在回答什麼

本會要為付費活動找售票方式，並在之後加上捐款與會員定期定額。這頁把各種現成方案並列，標出每個方案能做到什麼、缺少什麼，以及它們的無障礙實測分數，供設計團隊與理監事共同判斷。本頁不預設結論，讓事實與評估準則說話。

無障礙分數以 Google Lighthouse 為主要基準。每個分數都附實測網址，任何人可自行重跑核對。下一節說明這份報告用的兩個工具。

這份報告用的兩個工具：Lighthouse 與 Beacon

Google Lighthouse（主要基準）：Google 內建在 Chrome 的開源稽核工具，業界廣泛採用、公信力高。它的無障礙評分引擎是開源的 axe-core，產出 0 到 100 分。本報告對外以它為準。

Beacon（個人工具，提供分類細節）：由 Bertram 個人開發的無障礙檢測工具（非本會資產）。它的瀏覽器稽核層用的是與 Lighthouse 相同的引擎（axe-core），所以抓到的問題基本一致；差別在於 Beacon 額外把結果拆成十個分類（對比、鍵盤、螢幕報讀器、表單、媒體、動態、觸控、認知、響應式、AEO），標出每項的 WCAG 嚴重度，並附法規對照與修法建議。因為是個人工具、公信力不及 Google，本報告把 Beacon 放在輔助欄、只用來看分類細節，分數仍以 Lighthouse 為準。

兩者底層是同一個引擎（axe-core），所以兩欄分數方向一致、可互相佐證。分數的差距來自計分公式不同（Beacon 多了分類權重與嚴重度扣分），不是偵測能力的差異。

先確認的三個硬限制

  • Eventbrite 在台灣收不到付費款。它的金流走 PayPal，而 PayPal 自 2015 年起被台灣法規禁止處理國內交易（台灣賣家收台灣買家的票錢屬國內交易）。Eventbrite 對本會只能用於免費活動或國際曝光。
  • Stripe 對本會不適用。台灣登記法人無法在 Stripe 開本地收款帳戶，唯一路徑是另設美國公司，費率疊加約 5.4%，且開不了台灣電子發票、捐款收據對台灣捐款人無抵稅效力。
  • 台灣本地金流（綠界、藍新、TapPay）收得到錢，但無障礙多半不可控。它們預設把使用者導轉到金流商自己的頁面，那頁的無障礙由金流商決定，使用單位改不了，三家都沒有公開無障礙聲明。

每個選項能做什麼、缺少什麼

以下逐一列出。所有方案皆以「本會無工程人力」為前提評估。

netiCRM無障礙 87–92

專為台灣 NPO 設計的雲端託管系統，後台設定即可，已內建串接綠界、藍新、TapPay。

能做到

  • 售票、捐款、會員定期定額，一個系統全包
  • 自動開立捐贈收據、自動對帳
  • 完全免工程（廠商託管，行政人員可設定）
  • 語言宣告正確、允許縮放
  • 活動報名表單欄位皆有標籤、用 radio、可設定不含驗證碼

缺少

  • 無法自行修改無障礙（缺地標、對比不足，只能回報廠商）
  • 捐款表單那張帶 reCAPTCHA（驗證障礙風險，需確認版本）
  • 活動功能較陽春，頁面外觀客製有限
  • 精確方案費率需向廠商洽詢

WordPress + WooCommerce + 金流外掛無障礙 94（範例）

用網站系統加購物車外掛，裝綠界或藍新官方外掛。是後台設定、不是寫程式，會用 WordPress 的設計團隊可自行佈建。

能做到

  • 售票、捐款、會員（搭配外掛）
  • 無障礙自主可控：自選無障礙佈景主題，版面結構自己掌握
  • 本地付款齊全（信用卡、ATM、超商）
  • 結帳表單欄位完整有標籤、允許縮放（實測 22 欄全標籤）

缺少

  • 要長期自行維護一個 WordPress 站（更新、安全、備份），這是最大負擔
  • 會員定期定額需組多個外掛：WooCommerce Subscriptions（付費）加金流定期定額專業版（部分付費）
  • 電子發票、捐贈收據要另裝外掛
  • 信用卡輸入仍跳轉金流商頁面，那段不可控
  • 初期佈建工較多

原生售票平台（ACCUPASS / KKTIX）無障礙 79–82

台灣現成售票平台，免工程、原生台灣金流。

能做到

  • 售票，原生支援信用卡、ATM、超商代碼繳費（本地付款最齊）
  • 現成的活動探索人流、報到 App
  • 完全免工程（開帳號即可），活動功能成熟

缺少

  • 不做捐款、不做會員定期定額
  • 無障礙較弱且不可控（ACCUPASS 語言標錯、鎖死縮放；KKTIX 六類違規）
  • 無障礙缺口無法自行修，只能回報平台

Eventbrite（免費 / 曝光前台）無障礙 100

無障礙最佳、免工程，但收不到台灣付費款。

能做到

  • 免費活動報名（零金流問題）
  • 國際曝光、活動探索、SEO
  • 報名介面無障礙開箱即用（各方案最佳）

缺少

  • 台灣付費收款（PayPal 國內禁令，付費需改走台灣收款連結、分兩步）
  • 捐款、會員定期定額
  • 本地付款（超商、ATM）、電子發票、捐贈收據

金流收款連結（綠界 / 藍新）最低門檻

後台點一點產生付款網址與 QR code，免串接、免設定費。

能做到

  • 最低門檻收一筆錢（報名費、捐款）
  • 完全免工程
  • 本地付款（信用卡、ATM、超商）

缺少

  • 不是售票系統（無票種、名額、報名者資料、電子票、報到）
  • 結帳頁無障礙不可控（導轉）
  • 會員管理能力弱

Stripe本會排除

訂閱與無障礙在國際上是強項，但台灣落地困難。

能做到（理論上）

  • 業界最強的訂閱與會員扣款管理
  • 結帳元件無障礙水準佳

缺少 / 排除原因

  • 台灣登記法人無法本地申請，需另設美國公司
  • 費率疊加約 5.4%
  • 無台灣電子發票，捐款收據對台灣捐款人無抵稅效力
  • 撥款須經美國銀行中轉

本研究的限制（待補）

  • 登入後結帳步驟未測：ACCUPASS、KKTIX 真正的選票與填資料需帳號，未涵蓋，而那是表單無障礙最密集處。
  • 精確費率待洽詢：netiCRM 方案費、TapPay 與定期定額費率多為非公開，需向廠商確認。
  • 捐贈收據法源待確認：各家收據能否抵稅，需向廠商與稅務顧問雙重確認。
  • 真人測試未做：本頁全為自動化測試，上線前應找身障使用者實走流程，並用螢幕報讀器（NVDA / VoiceOver）驗證。
  • 本會自身條件待補：立案類型、公益勸募核可、活動量級等，會影響最終選擇。
